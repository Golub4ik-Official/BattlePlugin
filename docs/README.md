## Обзор механики

1. **Админ** назначает игроков в команды (`/battle team set`).
2. **Админ** создаёт точки захвата на карте (`/battle point add`).
3. **Админ** запускает битву (`/battle start <минуты> <команды> <название>`).
4. Во время битвы команды убивают друг друга и захватывают точки, набирая очки.
5. По истечении времени (или по `/battle stop`) битва завершается, определяется
   победитель, и результат сохраняется в историю.
6. Если установлены **PlasmoVoice** и **pv-addon-groups**, при старте битвы
   на каждую команду автоматически создаётся голосовой канал, участники
   подключаются к нему, а при завершении битвы каналы удаляются
   (см. [Конфигурация](/docs/config.md), раздел `battle.voice-groups`).
   Каналы защищены случайным паролем (противники не заходят вручную), а игроки
   с правом `battle.team.set` получают полные права аддона для кика/бана.
