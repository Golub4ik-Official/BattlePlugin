# Конфигурация

Конфиг находится в `plugins/BattlePlugin/config.yml`. Создаётся автоматически при
первом запуске плагина. Перечитывается командой `/battle reload` или перезапуском
сервера.

## Структура

```yaml
battle:
  # Длительность битвы по умолчанию (если в команде старта не указано время), в минутах
  default-duration-minutes: 30
  # Время, показываемое перед завершением битвы (в секундах)
  end-countdown-seconds: 10
  capture:
    # Радиус захвата точки (блоки)
    radius: 10
    # Время захвата/отката точки (секунды)
    time-seconds: 30
    # Очки за удержание захваченной точки
    hold-score: 1
    # Интервал начисления очков за удержание (секунды)
    hold-interval-seconds: 30
  bossbar:
    # Радиус показа полоски (блоки)
    radius: 30
  scoring:
    # Убийство противника: очки команде убийцы
    kill: 5
    # Смерть игрока команды: очки команде жертвы
    death: -2
    # Тимкилл: очки команде убийцы (без дополнительного штрафа за смерть)
    teamkill: -5
team:
  # Минимальное время на сервере (в часах) для назначения игрока в команду (/battle team set).
  # 0 — требование выключено (можно назначать любого игрока).
  min-playtime-hours: 0
discord:
  # URL Discord-вебхука для отправки итогов завершённой битвы.
  # Пустая строка — вебхуки выключены.
  webhook-url: ""
```

## Описание параметров

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `battle.default-duration-minutes` | `30` | Резервная длительность битвы в минутах (сейчас длительность всегда передаётся в `/battle start`) |
| `battle.end-countdown-seconds` | `10` | За сколько секунд до конца начинается обратный отсчёт в чате |
| `battle.capture.radius` | `10` | Радиус в блоках, внутри которого игроки влияют на захват точки |
| `battle.capture.time-seconds` | `30` | Время в секундах на захват/отбитие нейтральной точки |
| `battle.capture.hold-score` | `1` | Очки за один интервал удержания захваченной точки |
| `battle.capture.hold-interval-seconds` | `30` | Интервал в секундах, с которым начисляются очки за удержание |
| `battle.bossbar.radius` | `30` | Радиус в блоках, в котором игроку показывается bossbar ближайшей точки |
| `battle.scoring.kill` | `5` | Очки команде убийцы за убийство противника |
| `battle.scoring.death` | `-2` | Очки команде жертвы за смерть (без киллера в битве) |
| `battle.scoring.teamkill` | `-5` | Очки команде за тимкилл (убийство союзника) |
| `team.min-playtime-hours` | `0` | Минимальное время на сервере (в часах) для назначения игрока в команду. `0` — ограничение выключено |
| `discord.webhook-url` | `""` | URL Discord-вебхука для отправки итогов завершённой битвы. Пустая строка — выключено. Подробнее: [Discord-уведомления](discord.md) |

Связь параметров с механиками описана в разделах
[Очки и скоринг](scoring.md) и [Точки захвата](capture-points.md).
