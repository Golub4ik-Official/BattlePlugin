# Точки захвата

Точки захвата — ключевая механика битвы. Команды конкурируют за контроль над
точками, получая очки за захват и удержание.

Точки хранятся **только в памяти** — после перезапуска сервера их нужно
создавать заново.

## Управление точками

Создание (админ должен стоять в том месте, где будет точка):

```
/battle point add <название>
```

Удаление:

```
/battle point remove <название>
```

Список точек:

```
/battle point list
```

Все три команды требуют `battle.admin`, кроме `point list` — для него достаточно
`battle.status`.

## Состояния точки

| Состояние | Описание |
| --- | --- |
| `NEUTRAL` | Нейтральная: нет владельца, прогресс 0 |
| `CAPTURING` | Захватывается/отбивается: прогресс растёт или падает |
| `CAPTURED` | Захвачена: прогресс достиг максимума, есть владелец |

## Механика захвата

Каждый тик (1 секунда) плагин определяет **доминирующую команду** — команду со
строгим большинством игроков внутри радиуса захвата (`battle.capture.radius`,
по умолчанию 10 блоков). Внутри радиуса считаются только игроки, участвующие в
текущей битве.

- **Ничья или никого нет** — прогресс замирает.
- **Нейтральная точка, есть доминирующая команда** — прогресс растёт на 1 в
  секунду; при достижении `battle.capture.time-seconds` (по умолчанию 30) точка
  захватывается этой командой.
- **Точка принадлежит доминирующей команде** — остаётся захваченной.
- **Точка захвачена другой командой** — прогресс падает на 1 в секунду
  (отбитие); при падении до 0 точка переходит к доминирующей команде
  (событие «потерял(а) точку»).

## Очки за удержание

Захваченная точка начисляет владельцу очки за удержание. Каждые
`battle.capture.hold-interval-seconds` (по умолчанию 30 секунд) удержания команда
получает `battle.capture.hold-score` (по умолчанию 1) очко.

## Визуализация

- **Частицы**: вокруг каждой точки рисуется вращающийся цветной круг радиусом
  захвата. Цвет круга — цвет владельца (захвачена) или команды, ведущей захват;
  у нейтральной точки — серый.
- **Летающая табличка**: над точкой отображается название и прогресс в процентах,
  видна сквозь блоки. При захвате окрашивается в цвет команды и светится.
- **Bossbar**: игроку показывается полоса ближайшей точки в радиусе
  `battle.bossbar.radius` (по умолчанию 30 блоков). Цвет и заполненность полосы
  отражают состояние и прогресс точки. Если ближайшей точки нет — полоса скрывается.

## Статистика

Захват и удержание учитываются в статистике: события `POINT_START`,
`POINT_CAPTURED`, `POINT_LOST`, `POINT_HOLD`, а игроку, ближайшему к точке при
захвате, засчитывается «точек захвачено». Подробнее в
[Статистика](stats.md).
