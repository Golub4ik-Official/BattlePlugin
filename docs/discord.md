# Discord-уведомления

При завершении битвы плагин может отправлять итоги в Discord-канал через вебхук.

## Настройка

1. В Discord создай вебхук для нужного канала
   (Настройки канала → Интеграции → Вебхуки → Новый вебхук).
2. Скопируй URL вебхука и укажи его в `config.yml`:

```yaml
discord:
  # URL Discord-вебхука для отправки итогов завершённой битвы.
  # Пустая строка — вебхуки выключены.
  webhook-url: "https://discord.com/api/webhooks/..."
```

3. Перезагрузи конфиг: `/battle reload` (или перезапусти сервер).

Если `webhook-url` пуст — сообщения не отправляются.

## Что отправляется

При каждой завершённой битве (по таймеру или `/battle stop`) отправляется embed:

- **Заголовок** — номер и название битвы.
- **Победитель** — название команды-победителя (с учётом ярлыка) или «Ничья».
- **Команды** — для каждой команды: очки, убийства, смерти, тимкиллы, захваченные точки.
- **Топ игроков** — до 5 участников по убийствам с K/D.

Отправка выполняется асинхронно и не блокирует сервер.

## Важно

- URL вебхука содержит токен — **не публикуй его** в репозиториях и чатах.
- Для проверки можно использовать «сырой» вебхук (без бота) — плагину не нужны
  права бота в Discord.
