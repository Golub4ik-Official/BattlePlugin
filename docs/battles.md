# Битвы (жизненный цикл)

## Запуск

```
/battle start <минуты> <команда1> <команда2> [команда3] [команда4] <название>
```

Требуется право `battle.admin`.

- Количество команд: **от 2 до 4** (уникальные, повторы игнорируются).
- `<минуты>` — длительность, от 1 до 1440. Если битва уже идёт, запуск новой
  блокируется.
- `<название>` — произвольное название битвы (greedy string, пишется последним).
- Пример: `/battle start 30 red blue Битва за Киев`

При старте:
- Начинается **обратный отсчёт** (`start-countdown-seconds`, по умолчанию 10 сек):
  в чате каждую секунду объявляется «Битва начнётся через N сек.» с тикающим
  звуком (за последние 3 секунды — более громкий сигнал). Это время на подготовку.
- Пока идёт отсчёт, битва ещё не активна (очки и точки не начисляются);
  `/battle stop` в это время отменяет запуск.
- По истечении отсчёта: точки захвата сбрасываются в нейтральное состояние,
  объявляется «Битва началась!», участникам создаются sidebar-дашборды и bossbar,
  проигрывается звук старта, запускается тик (1 раз в секунду).

## Во время битвы

Каждый тик (1 секунда):
1. Уменьшается таймер битвы.
2. Обновляются точки захвата (см. [Точки захвата](capture-points.md)).
3. Начисляются очки за удержание точек.
4. Рисуются частицы вокруг точек.
5. Обновляются летающие таблички с названиями и прогрессом точек.
6. Обновляются дашборды и bossbar участников.

Анонсы:
- за 5 минут до конца — каждую минуту «До конца битвы: N мин.»;
- за `end-countdown-seconds` (по умолчанию 10) до конца — каждый тик
  «Битва завершится через N сек.» со звуком (за последние 3 секунды — более
  громкий сигнал);
- серии убийств в стиле **Dota 2**: всем участникам на экран (Title) выводится
  анонс (со звуком), когда игрок совершает серию убийств за короткое время.

## Анонсы серий убийств (Dota 2)

Когда игрок убивает противника, всем участникам битвы на экран выводится Title
с именем игрока и названием серии в одну строку:

- **`Игрок — FIRST BLOOD`** — первое убийство битвы;
- **`Игрок — DOUBLE KILL`** — 2 убийства подряд;
- **`Игрок — TRIPLE KILL`** — 3 убийства подряд;
- **`Игрок — ULTRA KILL`** — 4 убийства подряд;
- **`Игрок — RAMPAGE!`** — 5 и более убийств подряд.

Имя игрока окрашивается в цвет его команды, ниже мелким шрифтом выводится
подпись «убил(а) <жертва> (<оружие>)».

Убийства засчитываются в серию, если следующее произошло не позднее
`killstreak-window-seconds` (по умолчанию 8) после предыдущего. Смерть игрока
сбрасывает его серию. Тимкиллы в серию не засчитываются.

Вместе с Title проигрывается звук (можно отключить). Все параметры настраиваются
в `config.yml` → `battle.announcements` (см. [Конфигурация](config.md)).

## Завершение

Битва завершается автоматически по истечении времени или вручную:

```
/battle stop
```

Требуется право `battle.admin`.

При завершении:
- Определяется **победитель** — команда с наибольшим количеством очков. Если
  несколько команд набрали одинаковый максимум — ничья.
- Битва сохраняется в историю (см. [Статистика](stats.md)).
- Публикуется итоговое объявление со счётом всех команд.
- Убираются дашборды, bossbar и летающие таблички точек.
- Точки **не сбрасываются** после битвы (остаются в том состоянии, в котором
  битва закончилась), но при старте следующей битвы сбрасываются заново.

## Отключение плагина

При `onDisable` активная битва завершается принудительно (как `/battle stop`):
история сохраняется, так что незавершённая при выключении битва попадёт в неё.

## Перезагрузка конфига

```
/battle reload
```

Перечитывает `config.yml` без перезапуска сервера. Требуется право `battle.admin`.
