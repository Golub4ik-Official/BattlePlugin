# Команды (teams)

В плагине четыре фиксированные команды. Назначение игроков, заморозка и ярлыки
хранятся только в памяти — после перезапуска сервера назначения, заморозка и
ярлыки сбрасываются.

## Список команд

| Команда | Ключ | Цвет |
| --- | --- | --- |
| Красные | `red` | `#ff5555` |
| Синие | `blue` | `#5555ff` |
| Зелёные | `green` | `#55ff55` |
| Жёлтые | `yellow` | `#ffff55` |

При вводе названия команды в командах плагина принимаются как английские ключи
(`red`, `blue`, `green`, `yellow`), так и русские названия
(`красный`, `красная`, `красные`, `синий`, ..., `жёлтые` и т.п.).

## Назначение игрока в команду

```
/battle team set <игрок> <команда>
```

Требуется право `battle.team.set` (по умолчанию доступно только операторам —
см. [Права](permissions.md)). Команда перекрашивает ник игрока в цвет его команды
для **всех** онлайн-игроков: в чате (через `displayName` + плейсхолдер `{display}`
в ChatPlus), в табе и над головой.

### Требование по времени на сервере

Если в конфиге задан параметр `team.min-playtime-hours` (больше `0`), в команду
можно назначить только игрока, который провёл на сервере не меньше указанного
количества часов (время берётся из статистики игрока `play_time`, учитывается
всё время, включая пребывание AFK). При попытке назначить игрока с меньшим
временем команда отклоняется с сообщением о его текущем и требуемом времени.

Настройка применяется сразу при перезагрузке конфига (`/battle reload`).
По умолчанию `0` — ограничение выключено.

## Убрать игрока из команд

```
/battle team remove <игрок>
```

Требуется право `battle.admin`.

## Список назначений

```
/battle team list
```

Показывает всех назначенных игроков и их команды. Требуется право `battle.status`.

## Админ-команды для всей команды

Все команды ниже требуют право `battle.admin` и действуют на **онлайн-игроков**
команды.

### Телепорт команды

```
/battle team tp <команда> [игрок]
```

- Без `<игрок>` — телепортирует всех игроков команды к тебе (исполнителю).
- С `<игрок>` — телепортирует команду к указанному игроку.

### Заморозка команды

```
/battle team freeze <команда>
```

Запрещает движение всем онлайн-игрокам команды (обнуляет скорость ходьбы/полёта
и блокирует перемещение). Поворот головы остаётся доступен. Заморозка хранится
до `/battle team unfreeze <команда>` или до выхода игрока с сервера (при выходе
снимается).

### Разморозка команды

```
/battle team unfreeze <команда>
```

Снимает заморозку со всех онлайн-игроков команды и восстанавливает их обычную
скорость ходьбы/полёта.

### Копирование инвентаря админа команде

```
/battle team giveinv <команда>
```

Скопировать весь инвентарь исполнителя (включая надетую броню и предмет в оффхенде)
каждому онлайн-игроку команды. **Перед выдачей инвентарь каждого игрока команды
очищается** — старые предметы и броня удаляются. Исполнитель не получает копию.

### Ярлык команды (кастомное название)

```
/battle team label <команда> <название>
```

Устанавливает команде кастомный ярлык — название, которое показывается **вместо**
стандартного (Красные, Синие и т.д.) во всех местах: скорборд, bossbar, анонсы,
статистика, список команд. **Цвет команды при этом не меняется.** Пример:
`/battle team label red Друзья Пива` — команда red останется красной, но будет
называться «Друзья Пива».

- Ярлык хранится **в памяти** и сохраняется до перезапуска сервера.
- Действует только на название — команду по-прежнему можно указать как `red`
  (или по цвету) в командах, ключ команды не меняется.
- Для сброса:

```
/battle team unlabel <команда>
```

Возвращает команде стандартное название.

## Цветные ники

Ники перекрашиваются автоматически при назначении и обновляются раз в секунду
(задача в `BattlePlugin.onEnable`). При отключении плагина цветовые темы снимаются.

Окраска работает в двух режимах в зависимости от установленных плагинов:

- **Если установлен TAB** (`softdepend` в `plugin.yml`) — цвет ника в табе и над
  головой задаётся через TAB API (`NameTagManager` / `TabListFormatManager`).
  Плагин использует последний цвет префикса как цвет имени. При выходе игрока TAB
  сбрасывает свои значения, поэтому BattlePlugin заново применяет окраску при
  повторном входе (слушатель `PlayerLoadEvent` TAB).
- **Если TAB не установлен** — используется fallback через scoreboard-темы
  (`battle-red`, `battle-blue`, `battle-green`, `battle-yellow`) на дашборде каждого
  зрителя, независимо от его личного скорборда.

Цвет в **чате** не зависит от TAB: BattlePlugin задаёт игроку цветной `displayName`,
а чат-плагин должен выводить его через плейсхолдер `{display}` (см. настройку
`chat-format` в ChatPlus). Если чат-плагин использует `{player}` (обычный ник),
цвет команды в чате отображаться не будет.

## Участие в битве

Игрок считается участником битвы, если он назначен в команду, которая входит в
список команд запущенной битвы (`/battle start`). Зрители (игроки без команды или
из неучаствующей команды) не получают очки, дашборд и bossbar.
