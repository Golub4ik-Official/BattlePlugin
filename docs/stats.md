# Статистика и история

Каждая завершённая битва сохраняется в истории, а игроки накапливают личную и
командную статистику.

## Хранение

История хранится в **SQLite-базе данных** `plugins/BattlePlugin/battles.db` (YAML-файл
`battles.yml` больше не используется). Запись происходит при завершении каждой
битвы и при отключении плагина.

- база создаётся автоматически при первом запуске;
- при первом запуске плагин автоматически импортирует старую историю из
  `battles.yml` в базу, если такая история существовала;
- таблицы: `battles` (битвы), `battle_teams` (статистика команд), `battle_players`
  (личная статистика), `battle_events` (лента событий).

## Команды просмотра

Статистика последней битвы:

```
/battle stats
```

Статистика конкретной битвы по номеру:

```
/battle stats <id>
```

Статистика команды в битве:

```
/battle stats <id> team <команда>
```

Личная статистика:

```
/battle stats <id> me
```

Статистика другого игрока (требуется право `battle.stats.others`):

```
/battle stats <id> player <ник>
```

История завершённых битв (номер, название, победитель):

```
/battle history
```

Все команды требуют право `battle.status`, кроме `battle.stats.others` для
просмотра чужих данных.

## Что фиксируется

**Командная статистика** (`TeamSummary`):
- очки, убийства, смерти, тимкиллы;
- количество захваченных точек (`pointsCaptured`);
- количество наград за удержание (`holdAwards`);
- ярлык команды на момент битвы (`label`) — если команде был установлен ярлык
  (`/battle team label`), он сохраняется в записи и показывается в статистике даже
  после того, как ярлык был изменён или сброшен.

**Личная статистика игрока** (`PlayerSummary`):
- убийства, смерти, тимкиллы;
- K/D (убийства / смерти);
- лучшая серия убийств без смерти (`bestStreak`);
- количество захваченных точек.

В личной статистике (`/battle stats <id> me` и `/battle stats <id> player <ник>`)
дополнительно выводится:
- **кого убил игрок** (список жертв по имени с количеством повторных убийств);
- **тимкиллы** (каких союзников убил);
- **кто убивал игрока** (список киллеров с количеством раз);
- количество прочих смертей (не от участника битвы).

**Лента событий** (`StatEvent`): каждое убийство, тимкилл, смерть, начало
захвата, захват, потеря и удержание точки с указанием времени битвы и изменения
очков.

## Топ игроков

В итоговой статистике битвы игроки отсортированы по убыванию убийств — показывается
топ участников с их K/D.
