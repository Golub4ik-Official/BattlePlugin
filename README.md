# BattlePlugin

Плагин для Paper **1.21.11**, который позволяет проводить на сервере битвы между командами с захватом точек, очками за убийства и статистикой.

## Возможности

- Команды (до 4): red, blue, green, yellow.
- Командные битвы по таймеру с названием.
- Захват и удержание точек на карте с частицами и летающими табличками.
- Очки за убийства, смерти, тимкиллы и удержание точек (настраивается).
- BossBar ближайшей точки, sidebar-дашборды, цветные имена в командах
  (в чате, табе и над головой; интегрируется с TAB, см. [docs/teams.md](/docs/teams.md)).
- Статистика и история завершённых битв, лента событий.
- Статистика хранится в **SQLite-базе** (`battles.db`), а не в YAML.
- Личная статистика показывает, кого убил игрок и кто убивал его.
- В статистике сохраняются ярлыки команд (названия) на момент битвы.
- Требование по минимальному времени на сервере для назначения в команду (настраивается).
- Уведомления об итогах битвы в **Discord** через вебхук (URL настраивается).
- Сохранение статистики между перезапусками сервера.
- Детальная статистика битвы: first blood, динамика счёта, MVP, топ оружия,
  время удержания точек, полный состав участников.
- Личная статистика дополнена уроном (нанесён/получен), худшей серией смертей
  и оружием убийств/смертей.
- `/battle top [kills|kd|damage|captures]` — топ игроков за всё время.

## Сборка

Требуется JDK 21:

```bash
./gradlew build
```

Артефакт: `build/libs/BattlePlugin.jar`.

## Установка

1. Скопируй `BattlePlugin.jar` в папку `plugins` сервера.
2. Перезапусти сервер.
3. Настрой команды (`/battle team set`) и точки захвата (`/battle point add`).
4. Запусти битву: `/battle start 30 red blue Битва за Киев`.

## Команды

| Команда | Описание | Права |
| --- | --- | --- |
| `/battle help` | Справка | — |
| `/battle team set <игрок> <команда>` | Назначить игрока в команду | `battle.team.set` |
| `/battle team remove <игрок>` | Убрать игрока из команд | `battle.admin` |
| `/battle team list` | Список игроков по командам | `battle.status` |
| `/battle team tp <команда> [игрок]` | Телепортировать команду к себе (или к игроку) | `battle.admin` |
| `/battle team freeze <команда>` | Заморозить команду (запрет движения) | `battle.admin` |
| `/battle team unfreeze <команда>` | Разморозить команду | `battle.admin` |
| `/battle team giveinv <команда>` | Скопировать инвентарь админа (включая броню) всей команде | `battle.admin` |
| `/battle team label <команда> <название>` | Установить команде кастомный ярлык (цвет сохраняется) | `battle.admin` |
| `/battle team unlabel <команда>` | Сбросить ярлык команды на стандартное название | `battle.admin` |
| `/battle start <минуты> <команда1> <команда2> [команда3] [команда4] <название>` | Начать битву | `battle.admin` |
| `/battle stop` | Остановить битву | `battle.admin` |
| `/battle status` | Статус текущей битвы | `battle.status` |
| `/battle point add <название>` | Добавить точку на месте игрока | `battle.admin` |
| `/battle point remove <название>` | Удалить точку | `battle.admin` |
| `/battle point list` | Список точек | `battle.status` |
| `/battle stats [id]` | Статистика последней (или #id) битвы | `battle.status` |
| `/battle stats <id> team <команда>` | Статистика команды | `battle.status` |
| `/battle stats <id> me` | Личная статистика | `battle.status` |
| `/battle stats <id> player <ник>` | Статистика игрока | `battle.stats.others` |
| `/battle top [kills\|kd\|damage\|captures]` | Топ игроков за всё время | `battle.status` |
| `/battle history` | История завершённых битв | `battle.status` |
| `/battle reload` | Перезагрузить конфиг | `battle.admin` |

Подробнее о командах и механиках — в [вики](/docs/README.md).

## Разработка

Репозиторий использует GitHub Actions: при пуше тега `v*` плагин автоматически собирается и создаётся Release с `BattlePlugin.jar`. Правила для нейросети-ассистента описаны в [AGENTS.md](AGENTS.md).
