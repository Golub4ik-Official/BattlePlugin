# BattlePlugin

Плагин для Paper **1.21.11** — командные битвы с захватом точек, очками за убийства, статистикой и автоматическими голосовыми каналами.

## Возможности

- **Команды** — 4 фиксированные (red, blue, green, yellow), цветные ники в чате, табе и над головой.
- **Битвы по таймеру** — с обратным отсчётом перед началом, названием, автоматическим завершением и определением победителя.
- **Захват точек** — точки на карте с радиусом, таймером захвата/отката, начислением очков за удержание, частицами и летающими табличками.
- **Очки за действия** — убийство, смерть, тимкилл, удержание точек (всё настраивается в конфиге).
- **BossBar и скорборды** — полоска ближайшей точки, таблица очков для участников битвы.
- **Анонсы серий убийств** — FIRST BLOOD, DOUBLE KILL, TRIPLE KILL, ULTRA KILL, RAMPAGE в стиле Dota 2 (Title + звук).
- **Статистика** — история битв, личная/командная статистика, урон, оружие, first blood, MVP, топ оружия, время удержания точек. Хранится в SQLite (`battles.db`).
- **Топ игроков** — `/battle top` за всё время по убийствам, K/D, урону или захватам.
- **Discord-вебхук** — автоматическая отправка итогов завершённой битвы.
- **Голосовые каналы команд** — автоматическое создание канала PlasmoVoice на каждую команду при старте битвы (см. [Совместимость](#совместимость)).

## Как это работает

1. Админ назначает игроков в команды: `/battle team set <игрок> <команда>`
2. Админ создаёт точки захвата на карте: `/battle point add <название>`
3. Админ запускает битву: `/battle start 30 red blue Битва за Киев`
4. Команды сражаются — убивают друг друга и захватывают точки, набирая очки
5. По истечении времени битва завершается, определяется победитель, результат сохраняется в историю

## Совместимость

### TAB (цветные ники в табе и над головой)

BattlePlugin автоматически интегрируется с [TAB](https://modrinth.com/plugin/tab):

- Если TAB установлен — цвет ника в табе и над головой задаётся через TAB API.
- Если TAB не установлен — используется fallback через scoreboard-темы.
- Цвет в **чате** работает независимо от TAB (через `displayName` + плейсхолдер `{display}` в чат-плагине, например ChatPlus).

TAB указан как `softdepend` — плагин работает и без него.

### PlasmoVoice + pv-addon-groups (голосовые каналы)

BattlePlugin автоматически интегрируется с [PlasmoVoice](https://modrinth.com/plugin/plasmo-voice) и аддоном [pv-addon-groups](https://modrinth.com/plugin/pv-addon-groups):

- При старте битвы на каждую команду создаётся отдельный голосовой канал, участники подключаются автоматически.
- При завершении или остановке битвы все каналы удаляются.
- Каналы **защищены случайным паролем** — противник не сможет зайти в чужой канал вручную через `/groups join`. Участники подключаются автоматически, пароль им не нужен.
- Смена команды игрока во время битвы переводит его в канал новой команды.
- Игроки с правом `battle.team.set` получают максимальные права pv-addon-groups (`pv.addon.groups.*`) — могут кикать и банить из голосового канала через `/groups kick` и `/groups ban`.

Оба плагина указаны как `softdepend` — BattlePlugin работает и без PlasmoVoice/pv-addon-groups (голосовые каналы просто не создаются).

## Установка

1. Скопируй `BattlePlugin.jar` в папку `plugins` сервера.
2. Перезапусти сервер.
3. Настрой команды (`/battle team set`) и точки захвата (`/battle point add`).
4. Запусти битву: `/battle start 30 red blue Битва за Киев`.

Опционально: установите TAB, PlasmoVoice и pv-addon-groups для расширенного функционала.

## Команды

### Управление командами

| Команда | Описание | Права |
| --- | --- | --- |
| `/battle team set <игрок> <команда>` | Назначить игрока в команду | `battle.team.set` |
| `/battle team remove <игрок>` | Убрать игрока из команд | `battle.admin` |
| `/battle team list` | Список игроков по командам | `battle.status` |
| `/battle team tp <команда> [игрок]` | Телепортировать команду к себе (или к игроку) | `battle.admin` |
| `/battle team freeze <команда>` | Заморозить команду (запрет движения) | `battle.admin` |
| `/battle team unfreeze <команда>` | Разморозить команду | `battle.admin` |
| `/battle team giveinv <команда>` | Скопировать свой инвентарь (включая броню) всей команде | `battle.admin` |
| `/battle team label <команда> <название>` | Установить команде кастомный ярлык (цвет сохраняется) | `battle.admin` |
| `/battle team unlabel <команда>` | Сбросить ярлык команды | `battle.admin` |

### Управление битвой

| Команда | Описание | Права |
| --- | --- | --- |
| `/battle start <минуты> <ком1> <ком2> [ком3] [ком4] <название>` | Начать битву | `battle.admin` |
| `/battle stop` | Остановить битву (или отменить отсчёт запуска) | `battle.admin` |
| `/battle status` | Статус текущей битвы | `battle.status` |

### Точки захвата

| Команда | Описание | Права |
| --- | --- | --- |
| `/battle point add <название>` | Добавить точку на месте игрока | `battle.admin` |
| `/battle point remove <название>` | Удалить точку | `battle.admin` |
| `/battle point list` | Список точек | `battle.status` |

### Статистика

| Команда | Описание | Права |
| --- | --- | --- |
| `/battle stats [id]` | Статистика последней (или #id) битвы | `battle.status` |
| `/battle stats <id> team <команда>` | Статистика команды | `battle.status` |
| `/battle stats <id> me` | Личная статистика | `battle.status` |
| `/battle stats <id> player <ник>` | Статистика игрока | `battle.stats.others` |
| `/battle top [kills\|kd\|damage\|captures]` | Топ игроков за всё время | `battle.status` |
| `/battle history` | История завершённых битв | `battle.status` |

### Прочее

| Команда | Описание | Права |
| --- | --- | --- |
| `/battle help` | Справка | — |
| `/battle reload` | Перезагрузить конфиг | `battle.admin` |

## Права

| Право | По умолчанию | Описание |
| --- | --- | --- |
| `battle.admin` | op | Полный доступ; включает `battle.team.set` |
| `battle.team.set` | false | Назначение игроков в команды; включает `pv.addon.groups.*` |
| `battle.status` | true | Просмотр статуса, статистики, списков |
| `battle.stats.others` | false | Просмотр статистики другого игрока |

## Конфигурация

Конфиг `plugins/BattlePlugin/config.yml` создаётся автоматически. Перезагружается через `/battle reload`.

Основные параметры:

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `battle.default-duration-minutes` | 30 | Длительность битвы по умолчанию |
| `battle.start-countdown-seconds` | 10 | Обратный отсчёт перед началом (0 = сразу) |
| `battle.end-countdown-seconds` | 10 | Обратный отсчёт перед завершением |
| `battle.voice-groups.enabled` | true | Голосовые каналы команд (PlasmoVoice + pv-addon-groups) |
| `battle.voice-groups.channel-prefix` | Битва | Префикс названия голосового канала |
| `battle.voice-groups.password-protected` | true | Защищать каналы случайным паролем |
| `battle.capture.radius` | 10 | Радиус захвата точки (блоки) |
| `battle.capture.time-seconds` | 30 | Время захвата точки (секунды) |
| `battle.scoring.kill` | 5 | Очки за убийство противника |
| `battle.scoring.death` | -2 | Очки за смерть |
| `battle.scoring.teamkill` | -5 | Очки за тимкилл |
| `battle.announcements.enabled` | true | Анонсы серий убийств (Dota 2) |
| `team.min-playtime-hours` | 0 | Минимальное время на сервере для назначения в команду |
| `discord.webhook-url` | "" | Discord-вебхук (пусто = выключен) |

```bash
./gradlew build
```

Артефакт: `build/libs/BattlePlugin.jar`.
